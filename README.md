# Comparative-Effects-of-CHG-vs.-Soap-and-Water-on-Skin-Microbiota-of-the-Feet-in-Diabetics-
Accompanying files for the manuscript "Comparative Effects of Chlorhexidine Wipes vs. Soap and Water on Skin Microbiota of the Feet in Diabetics with Prior Foot Complications". Contains the scripts for all codes used for pre-processing and analysis. Also contains processed data used for analysis.
